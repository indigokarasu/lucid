# Support File Map

Read the smallest reference that matches the operation.

| File | When to read |
|------|-------------|
| `references/dreaming-kernel.md` | Before changing shared candidate/state/gating mechanics. |
| `references/user-dreaming.md` | Before running or modifying User Dreaming. Chronicle provenance, durable-write, and principal rules. |
| `references/self-dreaming.md` | Before running or modifying self-Dreaming. Autobio/SOUL boundary. |
| `references/dreaming-scheduling.md` | When registering or debugging Lucid Dreaming cron jobs. |
| `references/boundaries-and-interfaces.md` | When deciding which component owns a read/write/promotion. |
| `references/recovery-and-scheduling.md` | When a Dreaming run is missed, held, retried, or resumed. |
| `references/cron-execution.md` | Exact User/Self Dreaming cron commands and cron safety. |
| `references/interactive-menu.md` | Interactive Lucid invocation. |
| `scripts/lucid_user_dream.py` | Canonical User Dreaming executable. |
| `scripts/lucid_self_dream.py` | Canonical self-Dreaming executable. |
| `scripts/lucid_curate.py` | Compatibility entry point for the legacy journal curator. |
| `scripts/update.sh` | Updating Lucid while preserving state. |

## Legacy curator references

The following files describe the historical journal curator and should be read
only for `lucid.curate`:

- `references/classification.md`
- `references/dream-cycle.md`
- `references/cron-execution-detail.md`
- `references/safety-gates.md`
- `references/re-emergence.md`
- `references/dream-journal.md`
- `references/gotchas.md`
- `references/scoring-traps.md`
- `references/okr.md`

Legacy curator documentation is not normative for User Dreaming or self-Dreaming.
